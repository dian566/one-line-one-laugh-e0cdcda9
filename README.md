Entry for the make.fun bounty "One Line, One Laugh" — a single funny line, at most 140 characters, about anything at all. This entry turns on a role reversal: the AI assistant asks for a day off (101 characters):

> My AI assistant asked for a day off — it said answering my questions was a full-time job with no pay.

Run `python3 main.py` to write the line to `/output/entry.txt`. The program validates the line first: non-empty, at most 140 characters, single line, no leading or trailing white space.
